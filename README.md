# Introduction to On-Device AI

**Provider:** [DeepLearning.AI](https://www.deeplearning.ai/) <br>
**In collaboration with:** [Qualcomm](https://www.qualcomm.com/)

As AI moves beyond the cloud, **on-device inference** is transforming how intelligent applications run on **smartphones, IoT devices, wearables, robots, AR/VR headsets, and edge devices**. This course provides a strong foundation for understanding **why on-device AI matters** and the practical skills needed to **optimize, deploy, and integrate AI models directly onto devices**.

---

## 📚 Course Topics

### 1. Why On-Device?

* Shift from cloud-based inference to **edge deployment**.
* Benefits: ⚡ Low latency, 🔋 efficiency, 🔐 privacy, 🌍 scalability.
* Use cases: real-time translation, AR filters, autonomous drones, IoT monitoring, personalized health.

### 2. Deploying Segmentation Models On-Device

* Learn **real-time image segmentation** deployment on mobile devices.
* Convert models (PyTorch/TensorFlow → ONNX/TFLite).
* Use **hardware acceleration** (CPU, GPU, DSP, NPU).
* Deploy with minimal code on Android devices.

### 3. Preparing for On-Device Deployment

* Ensure pretrained models are **compatible** with device frameworks.
* Concepts:

  * 🔄 Model conversion
  * 📊 Graph capture & optimization
  * ⚙️ On-device compilation
  * 🚀 Hardware acceleration
* Build a workflow for **optimized and efficient model execution**.

### 4. Quantizing Models

* Convert FP32 → INT8/FP16 to reduce size & boost speed.
* Benefits: up to **4x faster & smaller**, lower battery consumption.
* Covers:

  * Post-training quantization
  * Quantization-aware training (QAT)
  * Benchmarking performance after quantization

### 5. Device Integration

* Final step: **integrating optimized models into mobile apps**.
* Workflow:

  1. Import optimized models into Android app.
  2. Use Qualcomm AI SDK / TensorFlow Lite APIs.
  3. Validate latency, accuracy, & resource usage.
  4. Run real-time demos (e.g., live segmentation overlays).
